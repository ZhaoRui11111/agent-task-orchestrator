# v0.1 compatibility evidence matrix

This is a non-normative evidence view. The authoritative policy is the
[versioning and compatibility contract](../reference/versioning-compatibility-contract.md).
A row records observed evidence only; it cannot define a version promise or turn
a planned target into support.

No runtime or v0.1 release exists today. Every row is therefore `unverified` and
there is no current supported platform, runtime, adapter, SDK, API, scheduler,
Git, or SQLite claim.

contract/schema versions, OS build/architecture/filesystem, tool/API versions,
commands or manual procedure, binary result, evidence location, observation
date, exclusions, and revalidation trigger required by the authoritative owner.
