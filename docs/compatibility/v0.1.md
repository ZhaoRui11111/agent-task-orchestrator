# v0.1 compatibility evidence matrix

This is a non-normative evidence view. The authoritative policy is the
[versioning and compatibility contract](../reference/versioning-compatibility-contract.md).
A row records observed evidence only; it cannot define a version promise or turn
a planned target into support.

No product runtime or v0.1 release exists today. Every row remains `unverified`
and there is no current supported platform, runtime, adapter, SDK, API,
scheduler, Git, or SQLite claim. A real feasibility observation can narrow a
technical unknown without satisfying the product-support evidence contract.
