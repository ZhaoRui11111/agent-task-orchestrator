# v0.1 compatibility evidence matrix

This is a non-normative evidence view. The authoritative policy is the
[versioning and compatibility contract](../reference/versioning-compatibility-contract.md).
A row records observed evidence only; it cannot define a version promise or turn
a planned target into support.

No released orchestration runtime or v0.1 release exists today. Every compatibility row
remains `unverified`, and there is no current supported platform, runtime,
adapter, SDK, API, scheduler, Git, or SQLite claim. The Domain Core and SQLite
persistence foundation plus the ProjectRegistry, local authorization, typed
application services, durable execution claims, reliable local Manual execution
loop, reconcile-first Manual dispatcher, the durable workspace foundation, and
the injected Phase 3 ProjectPolicy/gate/completion/integration/cleanup library
with local adapters, typed product facades, and versioned local Phase 1 plus
explicit-Manual Phase 2 CLI are implemented development-package capabilities
rather than platform-support claims. A real local observation can narrow a
technical unknown without satisfying the product-support evidence contract.
